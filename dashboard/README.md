# Dashboard README

## Live Demo

🌐 **Live Dashboard**: https://sentience-dashboard.vercel.app (deploy after build)

## Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## Build for Production

```bash
# Build static site
npm run build

# Output in ./dist directory
```

## Features

- Real-time portfolio tracking
- Interactive yield charts
- Kamino lending positions
- Strategy status monitoring
- Risk metrics dashboard
- Cyberpunk UI design

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Recharts
